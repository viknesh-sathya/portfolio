# 🖥️ Viknesh Sathya – Portfolio

A minimal, responsive **React portfolio website** showcasing my journey as a **Full‑stack MERN Developer** with 4+ years of experience.  
This portfolio highlights my skills, projects, and professional background, designed with recruiters and collaborators in mind.

---

## 🚀 Features

| Section                 | Description                                                                                                                                                                |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hero Section**        | Clean intro with role summary and a resume download CTA                                                                                                                    |
| **About Section**       | Highlights my roles as Full‑Stack Developer, Bug Hunter & Problem Solver, and Creative Builder — blending technical expertise with debugging skills and creative 3D design |
| **Skills & Experience** | Showcases a wide tech stack and career progression at Infosys, from Systems Engineer to Technology Analyst, with real-world backend, cloud, and deployment experience      |
| **Projects Slider**     | Interactive slider with overlays, filters, and responsive design                                                                                                           |
| **Footer**              | Quick contact links (LinkedIn, Gmail, GitHub)                                                                                                                              |
| **Responsive Layout**   | Optimized for both desktop and mobile                                                                                                                                      |
| **Clean UI/UX**         | Consistent styling, animations, and recruiter‑friendly presentation                                                                                                        |

---

## ⚡ Getting Started

### 1. Clone the repository

    git clone https://github.com/viknesh-sathya/portfolio.git

### 2. Install dependencies

    npm install

### 3. Run the app locally

    npm start

### 4. Build for production

    npm run build
